## 🧠 Selected Data & AI Projects

### Plantar Activity Recognition — Deep Learning for Multimodal Time Series
*Private repository*

A human activity recognition project using plantar pressure and inertial sensor data to classify **31 activities across 32 participants**.

- Built a pipeline for data cleaning, temporal alignment and sliding-window preprocessing.
- Compared five architectures: LSTM, TCN, CNN-BiLSTM and multi-branch networks with late fusion.
- Used **GroupKFold by participant** to evaluate generalisation to unseen individuals.

**Stack:** Python · PyTorch · Pandas · NumPy · SciPy · scikit-learn · Jupyter
